> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `CanKit.Pro.CANopen.Cia401` — catalogue, device side (first slice) and tool side of CiA 401-1 v3.1.0 — against the internal application seam, not packaged, and give the seam the one call it still lacks (default PDOs).

- Repository `CLAUDE.md` binds: a failing test first, a mutation for every "this test catches X", nothing asserted against a wall clock (`ManualTimeSource`, signals), API approval files untouched, XML/YAML well-formedness checked after editing.
- **No commit of type `feat` or `fix`.** Nothing a user can reach changes: the new project is `IsPackable=false` and all its types are `internal`. Use `refactor(canopen)`, `test(canopen)`, `build`, `docs`.

## Review Focus

1. **A device restored by Reset Node must be the device that powered on** — outputs back at their defaults, masks back, default PDOs back, analog TPDOs disabled again. Test in Task 8.
2. **An output the master never wrote must not move when a communication failure ends** — leaving the error state restores nothing by itself; the next write does. Test in Task 6.
3. **A remapped peer is read by its real mapping**, not by the profile default. Test in Task 9.
4. **An EDS that declares a catalogue object with another data type fails the open**; one that declares only some function blocks yields a device with exactly those. Test in Task 10.
5. **Polarity applies once**: an input set by the application, read back over SDO and sent in the TPDO shows the same inverted value, and the interrupt masks see logical, not physical, edges (§8.2.6). Test in Task 5.

## Decisions this plan makes

All internal, all changeable until publication; none was the maintainer's.

- **Analog default TPDOs are disabled by COB-ID bit 31 *and* `6423h` is FALSE** — §1 and §6.2.8 read differently; both are honoured.
- **`1029h` sub-indices 02h/03h (§6.2.4) are not added in this slice.** A device failure reported by the application follows sub-index 01h.
- **§7.2.3 NOTE 1** (outputs accepted only after the first heartbeat of the setting device) is not implemented in this slice.
- **`6003h` is stored without effect** — the filter itself is manufacturer-specific.
- **A device from an EDS does not add first-slice objects the file omits**; it behaves as their defaults.
- **Default PDOs above number 4 are written with an invalid COB-ID**, the one the node writes for an unassigned PDO: `C0000000h` for a TPDO, `80000000h` for an RPDO — CiA 301 defines defaults for four.
- **No commit of type `feat`**: unpackaged, internal.
- Bit-, 16-bit-, 32-bit- and float access objects are in the catalogue and readable through `Cia401Peer.ReadAsync`; the device side does not implement them (scope record: a later slice).
